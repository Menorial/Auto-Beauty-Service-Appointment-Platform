# 验证码页面「看不到」时如何排查

本仓库注册/登录页的验证码已写在 `src/views/Register.vue`、`src/views/Login.vue` 中。若浏览器里仍像旧版一样没有验证码：

## 1. 确认构建目录

务必在 **`Auto Beauty Service Appointment Platform\frontend`** 下执行：

```bash
npm run build
```

生成的 **`dist` 整个文件夹** 才是要部署的内容。不要只拷贝其中部分文件。

## 2. 缓存导致旧 JS

Vue 会把每个页面打成带 hash 的 `js/*.js`。若 **`index.html` 或旧 chunk 被缓存**，浏览器仍可能加载「没有验证码」的旧脚本。

- 本地开发：对开发者工具勾选 **Disable cache**，再刷新。
- 生产环境（Nginx 示例）：对 `index.html` 禁用强缓存：

```nginx
location = /index.html {
    add_header Cache-Control "no-store";
}
```

## 3. 一眼区分是否新包

- 注册页顶部应出现 **黄色提示条**：「安全验证（验证码）」。
- 登录页有 **蓝色提示条**：「登录需填写验证码」。

若这两项都没有，说明你当前访问的 **一定不是** 本仓库最新构建出来的前端。

## 4. 路由说明

`/login` 与 `/register` 已改为 **同步导入**（见 `src/router/index.js`），与首页等懒加载页面分离，减少「单独一个注册 chunk 被缓存」带来的困扰。
